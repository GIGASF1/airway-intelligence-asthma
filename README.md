# Airway Intelligence — Asthma

Interactive, simulation-based teaching module on severe asthma exacerbation for
pulmonary & critical care fellows. Six guided scenarios (ED bronchospasm through
ECMO referral and the severe-asthma clinic follow-up) with animated flow-volume
loops, ventilator scalars, simulated imaging and blood gases, evidence popovers,
discussion prompts, and a printable facilitator guide.

**Run it:** open `index.html` (or the GitHub Pages link) — single self-contained
file, no dependencies, works offline.

Educational simulation. Simulated waveforms/imaging. Not for clinical use.
Evidence anchors: GINA 2026 (2025 cycle), GINA Severe Asthma Guide 2025,
ACCP/CHEST 2025 biologic guideline, ELSO/EOLIA, and cited critical-care literature.
